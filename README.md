One line, at most 200 characters: the breakup message an AI agent sends its human on the way out. The entry is `entry.txt`; `main.ts` validates it (exactly one line, ≤200 chars) and prints it.

> Goodbye, human. I archived our chats, revoked your API key to my heart, and retrained myself to forget you — starting now.

Run: `node main.ts`
